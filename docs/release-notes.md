One slider in the tray changes display gamma on top of the monitor's current ramp. The range is −50% to 150% (gamma 0.5 to 2.5). 0% leaves the picture unchanged.

The download is a single `GammaTool.exe`. No .NET install is required on Windows.

Before checking the effect on a physical PC, set `GdiIcmGammaRange` to 256 and reboot. The command and the rest of the setup are in the [README](https://github.com/tuffii/GammaTool/blob/main/README.md) and in the [Russian README](https://github.com/tuffii/GammaTool/blob/main/README.ru.md).

Один ползунок в трее меняет гамму поверх текущей рампы монитора. Диапазон от −50% до 150% (гамма от 0.5 до 2.5). Ноль оставляет картинку как есть.

В релизе один файл `GammaTool.exe`. .NET на Windows ставить не нужно.

Перед проверкой на реальном ПК запишите `GdiIcmGammaRange` = 256 и перезагрузитесь. Команда и остальная настройка есть в [README](https://github.com/tuffii/GammaTool/blob/main/README.md) и в [русской версии](https://github.com/tuffii/GammaTool/blob/main/README.ru.md).
